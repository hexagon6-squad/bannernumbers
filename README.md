# Event Numbers

Print 6x9 banner numbers, one per letter page, with crop marks and a faint grey trim line. Set in Poppins Bold, sized to match the Tree Lighting banner file (8.5" tall digits, 90% width, 6x9 trim centered on 8.5x11).

## Event banner
1. Click a box on the mockup (`XX/XX FROM XX:XX TO XX:XX`) and type or tap a number. Leave boxes blank where you don't need a digit (like the first box in `4:00`).
2. "Numbers you need" shows how many of each number to print. Bump "Banners" if you're making more than one.
3. Click **Print**: the PDF preview opens in a new tab; print from there at Actual size. (Or Download PDF and open the file.) The title on the mockup is editable.

## Pick numbers
Tap any 0-9 (each tap = one page), or type a set like `1214 0800`, then print.

## Printing
**Download PDF** makes exact 8.5x11 pages; print the PDF at **Actual size / 100%**. If printing straight from the site, set **Margins: None** and **Scale 100%**.

Print settings (weight, height, width, faint grey trim line on/off + shade, crop marks) are under "Print settings". Everything is saved in your browser.

Poppins is bundled under the SIL Open Font License (`fonts/OFL.txt`).
Uses opentype.js (MIT) and pdf-lib (MIT), bundled in `lib/`.
